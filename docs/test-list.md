# 検証項目

## Windows
- Swift版と同じサイドバー、2列の音色カード、選択枠、色付きキートップ、独立した試聴ボタン、4画面の構成と入力試用欄を確認する。
- 高DPI画面でも縮小・切れがなく、キーボードで画面選択・音色選択・試聴・スイッチ・スライダーを操作できる。
- Given Windows 10/11 x64、When 起動、Then 設定と通知領域アイコンを表示し、閉じても常駐する。
- Given Raw Input登録、When 物理キーボードで別アプリへ入力、Then 上下音が発音し文字入力を遮断しない（手動確認が必要）。
- Given リピート・左右修飾キー・拡張キー・マウスボタン、When デコード、Then 独立した物理入力だけに音を対応させる。
- Given 無効・ロック・セッション切断・スリープ、When 入力または試聴、Then 発音せず、復帰後に保持キー状態を破棄する。
- Given 音量0・ピッチ±6・多数同時発音、When 実ミキサーでレンダリング、Then 有限・範囲内の出力を返す。
- Given 元録音182個、When PCM変換して実ミキサーへ全長schedule、Then 全件が48kHzステレオ・有限・非ゼロ出力となる。
- Given 壊れた設定・日付変更、When 復元／記録、Then 設定を回復し日次と累計以外を保存しない。
- Given ランタイム未導入環境用のZIP、When パッケージ化、Then ランタイム・同じ182録音・出典・SHA256を含める。
- Given 入力登録失敗・音声出力失敗、When 設定画面を表示、Then エラーと再試行を提示し、入力失敗時も試聴できる。
- Given 明示的なLaunch at login操作、Then 現行実行ファイルをユーザー単位で登録／解除する。検証作業では自動登録しない。
- Windowsでは`make check`と`make windows-package`、macOSでは従来の`make check`を実行する。Windows CIはZIPを成果物に保存し、自動公開しない。

## 正常系
- 7音色の上下音を選択・試聴できる。
- 音量、ピッチ、左右の広がり、修飾キー、マウス音を設定できる。
- 当日・累計統計と設定が再起動後も復元される。
- LPで試聴でき、GitHub、Releaseへのリンクが一致する。

## 境界と失敗
- 無効・ロック・キーリピートでは発音しない。
- NSEvent.mouseEventがキーボード専用プロパティへ触れない。
- 左右の修飾キーの押下と解放を区別する。
- 壊れた設定を既定値へ回復し、値を許容範囲へ制限する。
- 未許可時の状態を表示し、試聴を利用できる。
- Web音声の取得失敗や連続切替から回復できる。

## 音声回帰
- 全182サンプルを48kHzステレオFloat32へ変換し、実グラフの出力が有限・非ゼロである。
- 同梱した録音は許可された元データと一致し、有効なWAVである。

## セキュリティ・公開
- 公開対象に資格情報、絶対個人パス、旧ブランド、第三者取得素材、キャッシュを含めない。
- ソースとLPの相互リンク、Releaseの実ダウンロード、SHA256を確認する。

## 手動確認
- 通常のマウスでタブ・トグル・試聴を操作し、試聴完了後も稼働する。
- LPをデスクトップと狭い画面で表示し、試聴とリンクを検証する。
- 公開したLPをブラウザーで確認する。

## 固定署名の回帰
- Given 署名IDの明示指定、When 署名、Then そのIDでのみ署名する。
- Given 固定署名設定、When ビルド、Then 同じIDを再使用する。
- Given 固定署名設定の破損または署名失敗、When ビルド、Then 停止しアドホックに切り替えない。
- Given 署名後のDRがcdhashのみ、When 固定署名の検証、Then 失敗する。
- Given 別出力先の内容が異なる2版、When 同じ証明書で署名、Then DRが一致し、各版の改ざん検証が成功する。
- Given KBSD_APP_PATHの別ビルド出力、When Release ZIPを作成、Then 既定のアドホック版ではなく指定した署名済み.appを格納する。
