# 検証項目

## 正常系
- 7音色の上下音を選択・試聴できる。
- 音量、ピッチ、左右の広がり、修飾キー、マウス音を設定できる。
- 当日・累計統計と設定が再起動後も復元される。
- LPで試聴でき、GitHub、Releaseへのリンクが一致する。

## 境界と失敗
- 無効・ロック・キーリピートでは発音しない。
- NSEvent.mouseEventがキーボード専用プロパティへ触れない。
- 左右の修飾キーの押下と解放を区別する。
- 壊れた設定を既定値へ回復し、値を許容範囲へ制限する。
- 未許可時の状態を表示し、試聴を利用できる。
- Web音声の取得失敗や連続切替から回復できる。

## 音声回帰
- 全182サンプルを48kHzステレオFloat32へ変換し、実グラフの出力が有限・非ゼロである。
- 同梱した録音は許可された元データと一致し、有効なWAVである。

## セキュリティ・公開
- 公開対象に資格情報、絶対個人パス、旧ブランド、第三者取得素材、キャッシュを含めない。
- ソースとLPの相互リンク、Releaseの実ダウンロード、SHA256を確認する。

## 手動確認
- 通常のマウスでタブ・トグル・試聴を操作し、試聴完了後も稼働する。
- LPをデスクトップと狭い画面で表示し、試聴とリンクを検証する。
- 公開したLPをブラウザーで確認する。

## 固定署名の回帰
- Given 署名IDの明示指定、When 署名、Then そのIDでのみ署名する。
- Given 固定署名設定、When ビルド、Then 同じIDを再使用する。
- Given 固定署名設定の破損または署名失敗、When ビルド、Then 停止しアドホックに切り替えない。
- Given 署名後のDRがcdhashのみ、When 固定署名の検証、Then 失敗する。
- Given 別出力先の内容が異なる2版、When 同じ証明書で署名、Then DRが一致し、各版の改ざん検証が成功する。
- Given KBSD_APP_PATHの別ビルド出力、When Release ZIPを作成、Then 既定のアドホック版ではなく指定した署名済み.appを格納する。
