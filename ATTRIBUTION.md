# Asset provenance

## Keyboard recordings

The 182 keyboard recordings originate from Klack's sound previews at `https://cdn.tryklack.com/sounds/preview/`. Permission to redistribute the recordings in this distribution has been confirmed. Ownership remains with the original rights holders; kbsd does not claim authorship of these recordings or grant additional reuse rights.

| kbsd resource directory | Original preview directory / sound |
| --- | --- |
| slate | japanese-black / Japanese Black |
| violet | crystal-purple / Crystal Purple |
| pebble | oreo / Oreo |
| paper | cardboard / Cardboard |
| honey | milky-yellow / Milky Yellow |
| ruby | super-red / Super Red |
| cream | cream / Cream |

Each directory contains 13 key samples, with independent down/up files. kbsd normalizes the recordings to a common playback format at runtime.

## First-party artwork and UI

The kbsd icon is original geometric artwork generated by `scripts/generate_icon.swift`; `public/icon.svg` is its vector companion. Application screenshots are captured from the kbsd application built from this repository. The landing page uses original HTML/CSS, system fonts, and the kbsd app screenshot.

Native UI symbols use Apple's system-provided SF Symbols at runtime. No original website images, wallpaper, tracking scripts, or website source code are included.
