    On Windows, run the installer and search for kbsd in Start. On Mac, unzip kbsd and move it to Applications. The Mac release is locally signed and isn’t notarized. macOS may show a security warning; review the source and Apple’s opening instructions before proceeding.

    Windows is ready without extra permissions. On Mac, open General in kbsd, then Open System Settings. Allow kbsd in Accessibility (called Device Control & Data Access on some macOS versions). No permission is needed for in-app previews.

A few things to know.

Which computers can run kbsd?

kbsd runs on Apple Silicon Macs with macOS 14 or later and Windows 10/11 x64. An Intel Mac build is not included. Both Windows downloads include the .NET runtime.

How do I install kbsd on Windows?

Download and run the Windows installer. It installs for your user without administrator access and adds kbsd to the Start menu. Search for kbsd to open it, even while it is already running in the notification area. To remove it, use Windows Settings → Apps → Installed apps. The installer and app are not Authenticode signed.

Launch at login is optional: turn it on in kbsd → General. The portable ZIP is also available; extract the whole folder and run kbsd.exe.

Does kbsd record what I type?

No. It uses physical key events to choose a sound, without reading typed characters or storing a key history. Only daily and total counts are saved locally.

Why does it only play inside the app?

Keyboard access hasn’t been granted to the current app. Open General → Open System Settings. If an older build is already allowed, remove that entry, add the current kbsd.app, and click Check again.

Where do the sounds come from?

The switch recordings come from Klack’s sound previews and are included with permission. Their original rights holders retain ownership. See the repository’s asset attribution for details.

What is included in this release?

Seven sounds, press/release feedback, volume and pitch controls, stereo width, modifier and mouse sounds, local counts, and optional launch at login. Head-tracked spatial audio and automatic updates are not included.
